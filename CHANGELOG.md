# Changelog

## 0.1.1

- Fixed Jupyter notebooks not showing: their overlay was rendered behind the editor area.
- Notebook cells and toolbar are now transparent, so the wallpaper shows through.
- Fixed a refresh loop that made the interface flicker.
- Removed the blur filter from the editor area, which could interfere with webview-based editors.
- Wallpaper of the Horizon theme no longer carries embedded metadata.

## 0.1.0

- Three themes: DSN Nova Dark, DSN Nova Light and DSN Nova Horizon.
- Wallpaper per theme, or your own image with fill, fit, stretch, center and tile modes, for the whole window or the editor area only.
- Live DSN Nova panel (diamond button in the activity bar, `Ctrl+Alt+N`) with tabs for Wallpaper, Zones, Windows, Effects, Colors and Fonts. No numbers to type.
- Seven functional code colors (cyan, blue, purple, green, orange, red, gold), editable from the panel.
- Glass transparency for sidebar, activity bar, panel, status bar, pages, popups and menus.
- Text legibility effect (glow in Dark, shadow in Light) and neon borders and scrollbar.
- Font groups and interface font selection.
